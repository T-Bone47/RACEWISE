## Brand & Style

This design system is calibrated for precision motorsport intelligence, forensic trace analysis, and real-time strategic modeling. The visual atmosphere fuses the relentless analytical density of MoTeC i2 with the surgical, keyboard-first responsiveness of modern high-performance engineering suites and the structured epistemics of Palantir evidence triage.

The aesthetic rejects high-key racing garnishes, glossy stadium neons, and consumer-grade card metaphors. Instead, it creates an authoritative, low-reflectance, high-legibility command deck. Visual hierarchy is established through meticulous contrast differentials, micro-borders, and disciplined typographical geometry. Interface surfaces recede into deep slate-graphite, allowing high-density scalar metrics, epistemic tags, and real-time telemetry delta plots to function as primary signal layers.

Key style principles:
- **Zero Decorative Overhead:** Every visual boundary, tick line, surface lift, and chromatic accent must correspond to a data structure, certainty status, or telemetry threshold.
- **Instrument Density:** Information layouts are engineered for high-density side-by-side comparative diagnostics (telemetry traces, lap delta tables, and counterfactual trees) without visual fatigue.
- **Epistemic Integrity:** Color operates strictly as categorical and semantic truth states (proven fact, calculated parameter, probabilistic inference, synthetic counterfactual, unverified assumption).

## Colors

The system uses a calibrated multi-surface dark architecture constructed on low-chroma slate-graphite foundations. Color saturation is strictly rationed: chromatic hues are reserved for system states, verification results, epistemic classifications, and high-priority telemetry triggers.

### Base Tones & Surfaces
- **Canvas Base (`#0B0D10`):** The primary view boundary, root background, and canvas layer.
- **Panel Surface (`#111418`):** Docked panes, telemetry chart viewports, analytical sidebars, and trace tracks.
- **Element Surface (`#171B22`):** Elevated modules, nested parameter tables, command palettes, and active cells.
- **Hover/Interactive Surface (`#1E232C`):** Micro-hover responses, active telemetry scrub highlights, and table row emphasis.

### Structural Lines
- **Border Subtle (`#232934`):** Grid dividers, metric separator lines, and chart axes.
- **Border Highlight (`#2F3746`):** Focused inputs, active inspector targets, and pinned telemetry channels.

### Core Signal Accents
- **Primary Accent (`#00E5FF`):** Micro-cursor indicators, active channel flags, current delta scrubbers.
- **Secondary Accent (`#3875FF`):** Key structural actions, active keyboard-navigated focal rings, pinned telemetry channels.

### Epistemic State Engine
To maintain unambiguous analytical provenance across racing investigations, claims and data points carry mandatory categorical status colors:
- **FACT (`#3B82F6`):** Direct sensor readout, hardware log, FIA timing feed. Unimpeachable record.
- **CALCULATION (`#06B6D4`):** Deterministic derivative calculation (e.g., differential slip percentage, aero map downforce index).
- **INFERENCE (`#F59E0B`):** Probabilistic algorithm, tire degradation curve estimation, acoustic analysis deduction.
- **COUNTERFACTUAL (`#8B5CF6`):** Simulated alternate scenarios (e.g., box-lap pit delta under VSC, undercut simulator).
- **ASSUMPTION (`#64748B`):** Human baseline parameters, nominal track temperature coefficient, estimated fuel burn.

### Verification Status Indicators
- **SUPPORTED (`#10B981`):** Claim confirmed by correlating physical traces.
- **PARTIALLY_SUPPORTED (`#F59E0B`):** Signal detected within incomplete confidence bounds.
- **CONTRADICTED (`#EF4444`):** Telemetry or physical sensor explicitly refutes hypothesis.
- **NOT_SUPPORTED (`#64748B`):** Insufficient telemetry correlation.
- **NOT_TESTABLE (`#52525B`):** Sensor dropout, missing sector packet, or uninstrumented telemetry channel.

## Typography

Typography functions as a precision instrument: legible under high data density, zero glyph ambiguity, and mathematically consistent alignment across variable-speed streams.

### Architectural Font Rules
- **Inter** handles narrative synthesis, investigation hypothesis records, contextual headers, and structural control typography. Tabular figures (`tnum`) and slashed zeros (`cv01` / `zero`) are enforced globally.
- **JetBrains Mono** governs all mathematical, temporal, spatial, and mechanical metrics. Every speed (km/h), throttle percentage (%), delta variance (±0.000s), memory offset, packet timestamp, and cryptographic telemetry trace hash must be rendered exclusively in `JetBrains Mono`.

### Typographic Discipline
- **Tabular Numerals Always Active:** Monospaced alignment prevents layout shifts and eye wander during 50Hz and 100Hz real-time telemetry scrubbing.
- **Case Hierarchy:** Micro-labels, axis legends, and epistemic status badges utilize strict full caps with positive letter spacing (+0.02em to +0.05em) to maintain clarity at sizes below 11px.
- **No Text Larger than 28px:** This is a dense investigative environment; display typography is constrained to ensure screens prioritize trace data over blank space.

## Layout & Spacing

The layout is structured around an ultra-compact, high-efficiency grid optimized for multi-pane split workflows, rapid resizing, and synchronized time-axis telemetry scrubbers.

### Layout Model
- **Grid Paradigm:** Fluid, panel-docked modular frame. The viewport splits into multi-column and multi-row workbenches separated by hairline dividers rather than dead margins.
- **Horizontal & Vertical Density:** Standard spacing baseline is fixed to an absolute 4px/8px modular cadence (`space-xxs: 2px`, `space-xs: 4px`, `space-sm: 8px`, `space-md: 12px`, `space-lg: 16px`).
- **Workspace Structure:**
  - **Global Header / Context Strip (36px fixed height):** Session status, track status flags, current lap time, timecode cursor, sync status.
  - **Left Rail (320px default / resizable / collapsible):** Evidence graph tree, hypothesis ledger, channel selector.
  - **Center Canvas (Fluid):** Primary trace viewer, lap split delta delta (ΔΔ), synchronized scatter plots, and corner apex phase breakdowns.
  - **Right Inspector (360px default):** Epistemic proof viewer, parameter inputs, calculated telemetry derivations, run log.

### Responsive & Layout Adaptation
- **Desktop (1440px+):** Tri-pane continuous investigation mode with persistent trace scrubber and synchronous cross-hair cursors across all graphs.
- **Compact Desktop / Field Monitor (1024px - 1439px):** Auto-collapse inspector into a persistent tabbed drawer; evidence tree converts to a modal command selector.
- **Field Terminal (< 1024px):** Single-column stacked telemetry stack; interactive split-screens transition into synchronized sequential tabs.

## Elevation & Depth

Visual hierarchy is achieved through precise tonal stepping and micro-borders rather than ambient diffusion or deep drop shadows. Shadows in real-time engineering platforms introduce visual smudge that impedes rapid line-scan perception.

### Structural Depth Architecture
- **Layer 0 (Canvas Base - `#0B0D10`):** The non-interactive foundational workspace floor.
- **Layer 1 (Recessed Viewports - `#0E1014` with inner 1px border `#1E232C`):** Used for trace canvases, time-series plotting strips, and log streams.
- **Layer 2 (Standard Workspace Panels - `#111418` framed with 1px `#232934`):** Fixed dock containers, sidebars, and control bars.
- **Layer 3 (Surface Elements - `#171B22` with 1px `#2F3746` border):** Active inspect panels, telemetry channel tags, data cards, and interactive table nodes.
- **Layer 4 (Command Palettes & Overlay Flyouts - `#171B22` with 1px `#3875FF` or `#2F3746` border + subtle tight occlusion shadow):** `0 4px 16px -2px rgba(0, 0, 0, 0.7)`. Shadows are hard-edged, restrained, and achromatic.

### Focus & Crosshair Indicators
Elevation is reinforced laterally: active rows, locked channels, and pinned investigative evidence nodes draw focus through a 1px vertical left-accent bar tinted to the respective epistemic state color, rather than z-index lifting.

## Shapes

The geometric vocabulary is functional and structural. Sharp angles and micro-radii emphasize mechanical stability, tool-like precision, and structural spatial boundaries.

### Border Radius Rules
- **Structural Windows & Major Panels:** `0px` radius. Internal panels dock seamlessly without pillowed negative gaps.
- **Inputs, Buttons, Micro-Badges & Interactive Tiles:** `0.25rem` (`4px`) maximum radius (`roundedness: 1`).
- **Telemetry Channel Pills & Tag Chips:** `2px` or `4px` corner bevel. Pill-shaped circular ends (`rounded-full`) are prohibited except for telemetry point dots and connection status pings.
- **Dividers & Tick Markers:** Strict `0px` rectangles to guarantee alignment with individual screen pixels.

## Components

### Buttons & Trigger Elements
- **Primary Tool Action:** Solid background (`#00E5FF` at 10% opacity, border 1px solid `#00E5FF`, text `#00E5FF`). On hover: background `#00E5FF` at 20% opacity. Height: `28px` for compact tools, `32px` standard.
- **Secondary Action:** Background `#171B22`, border 1px solid `#232934`, text `#94A3B8`. Hover: border `#2F3746`, text `#F8FAFC`.
- **Destructive/Abort Action:** Background `#EF4444` at 10% opacity, border 1px solid `#EF4444`, text `#EF4444`.
- **Keyboard Shortcut Indicators:** Integrated into button edges as right-aligned monospaced glyphs (e.g., `⌘K`, `E`, `SPACE`) rendered in `#64748B` at 10px.

### Epistemic & Evidence Badges (Chips)
- Structured indicator tags display categorical truth status.
- **Structure:** 18px total height, monospace 10px text, uppercase, 0.05em tracking, 2px corner radius.
- **Coloration:** Background set to status color at 8% opacity; text set to full-saturation status color; left border 2px solid status color (`FACT`: blue, `CALCULATION`: cyan, `INFERENCE`: amber, `COUNTERFACTUAL`: violet, `ASSUMPTION`: slate).
- **Verification Nodes:** Mini square icon (4px) embedded on the leading edge showing solid fill for `SUPPORTED`, dashed for `PARTIAL`, cross for `CONTRADICTED`.

### Telemetry Channels & Signal Tags
- Compact tokens denoting tracked telemetry variables (e.g., `vCar`, `rEngine`, `pBrakeF`, `SteerAngle`).
- Displays a leading 2px colored line representing the channel trace line color as plotted on the time-distance graph.
- Monospace 11px font with right-aligned numeric readouts updating in real-time.

### Data Tables & Telemetry Scrubbers
- Row height fixed at dense 24px or comfortable 28px.
- Zero alternating striped backgrounds; table lines utilize single-pixel `#232934` rules.
- Column headers: JetBrains Mono, uppercase, 10px, `#64748B`, with explicit unit tags (e.g., `SPEED [KM/H]`, `DELTA [S]`, `THROTTLE [%]`).
- Row hover: flat background `#1A2028`. Active/scrubbed row: `#1E2632` with left edge marked by a 2px `#00E5FF` notch.

### Inputs & Scrub Fields
- Background `#0B0D10`, border 1px solid `#232934`, text `#E2E8F0`. Focus state: border 1px solid `#3875FF`, subtle box-shadow inset `0 0 0 1px #3875FF`.
- Number inputs for parameters (e.g., tire degradation exponents, fuel mass) support click-drag horizontal scrubbing directly on the value with immediate cursor lock.

### Evidence Graph Cards
- Background `#111418`, border 1px solid `#232934`, padding `space-sm` (8px).
- Header contains hypothesis reference code (e.g., `HYP-042`), timecode anchor (`LAP 43 1:18.234`), and epistemic status chip.
- Body displays brief rationale in `Inter` 12px, followed by an inline mini sparkline showing the corresponding telemetry anomaly.
